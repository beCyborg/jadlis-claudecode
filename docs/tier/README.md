# Тир 0 — рабочее место

Подписка, приложение, одна команда. На выходе Claude Code настроен один в один с моей
машиной: язык, правила ответа, память, терминал и папка, где живут заметки.

## Зачем

Результат на 80% решает контекст о твоей жизни и на 20% — сама задача. Пока контекста
нет, агент угадывает и убедительно ошибается.

Тир 0 строит место, куда этот контекст будет складываться: настроенный Claude Code,
включённая память, рабочая папка `~/Jadlis` и терминал, который открывается прямо в ней.
Всё остальное на маршруте опирается на него.

Плагин `jadlis-claudecode` делает это одной командой, а не инструкцией на двадцать шагов.

## Как поставить

Три шага перед плагином, потом одна команда.

1. **Подписка Claude.** Нужен план **Max**: шаблон настроек ставит `model: "opus[1m]"` —
   Opus с окном на 1M токенов, а на Pro такая модель списывает usage-кредиты. Условия и
   цены — на claude.ai.
2. **Десктопное приложение Claude Code.** Скачай с
   [страницы установки](https://code.claude.com/docs/en/desktop-quickstart), запусти,
   войди в аккаунт, открой вкладку **Code** и выбери папку.
3. **CLI `claude`.** Приложение его **не ставит** — а команды `claude plugin …` нужны
   для плагинов. Поставит сам `/claudecode`; либо руками:
   `curl -fsSL https://claude.ai/install.sh | bash`.

Дальше вставь этот блок в Claude Code целиком:

```text
Ты — установщик. Выполни ровно эти шаги и ничего сверх них:
1. Bash: claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
2. Bash: claude plugin install jadlis-claudecode@jadlis
3. Скажи мне: «Набери /claudecode»
Ничего не читай, не создавай и не ставь помимо этого.
```

Руками — те же две команды в терминале:

```bash
claude plugin marketplace add https://github.com/beCyborg/jadlis-hub
claude plugin install jadlis-claudecode@jadlis
```

Полный HTTPS-URL обязателен: короткая форма `owner/repo` клонируется по SSH, а SSH-ключа
у нового пользователя обычно нет.

## Как пользоваться

Одна команда. Она спрашивает и показывает дифф до того, как что-то менять.

```text
/claudecode          # весь маршрут: проба → зависимости → терминал → ~/Jadlis → ~/.claude → итог
/claudecode статус   # только проба PASS/FAIL, ничего не ставит и не меняет
```

Три сценария:

- Чистый Mac: `/claudecode`, дальше по шагам.
- Claude Code уже настроен, нужен только терминал: `/claudecode`, на шаге 5 отвечай
  «пропустить» — слияние настроек не тронет ничего без явного «да».
- Нужна папка заметок и её структура: это следующий плагин, `/jadlis-obsidian`.

**Проверка одним действием.** Открой новую вкладку iTerm2. Она должна открыться в
`~/Jadlis`; набери `cld` — поднимется tmux-сессия с именем папки и запустится Claude Code.
Получилось — тир 0 закрыт, дальше `/jadlis-hub`.

## Границы и стоимость

Чего тир 0 **не** делает:

- Не покупает подписку и не ставит приложение за тебя — это шаги 1–2 выше.
- Не строит структуру папок под методологию и не заводит метрики.
- Не заводит ключи API: они живут в Связке ключей macOS и приезжают позже.
- Не перезаписывает существующие `settings.json`, `.zshrc` и `~/.tmux.conf` молча —
  сливает, дописывает между маркерами или спрашивает.
- Не работает вне macOS: динамический профиль iTerm2, `defaults` и Homebrew — про Mac.

Стоимость: нужна подписка Claude Max и macOS. Homebrew, git, jq, Node.js, python@3.13,
uv, poppler, tmux, iTerm2 и шрифт — бесплатны. Ни одного платного запроса тир 0 не делает.

## Десктоп или терминал

Этот тир ставит терминальный путь, потому что на нём стоит всё остальное: `cld`,
tmux-сессии, строка состояния и запуск ритуалов по расписанию.

Общее у обоих: одни и те же `CLAUDE.md`, `~/.claude/settings.json`, MCP-серверы, хуки,
скиллы, плагины и модели. Настроил в одном — работает в другом.

| Только в терминале | Только в десктопе |
|---|---|
| режим разрешений `bypassPermissions` без диалогов | Dispatch-сессии в боковой панели |
| `--print` и Agent SDK — свои запуски по расписанию (`launchd`, `cron`) | задачи по расписанию внутри приложения |
| строка состояния и команды-диалоги (`/permissions`, `/config`, `/keybindings`) | панели чата, диффа, терминала, файлов и браузера |
| команды агентов (agent teams) | отдельный git-worktree на каждую параллельную сессию |
| Remote Control — сессия живёт на машине, продолжается с телефона | вложения: картинки и PDF прямо в промпт |

Отдельно: приложение **не ставит** CLI `claude`. Внутри у него свой встроенный движок,
но команды `claude …` в Bash берутся из отдельной установки — её делает `/claudecode`.
